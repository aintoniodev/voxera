# Taxonomía de emojis contextuales (español + inglés)

Regla de oro: el emoji añade SIGNIFICADO a la palabra, no la adorna. Si tienes que
pensarlo más de 5 segundos, no lleva emoji. Máximo 1 sticker cada ~3 s de habla.

| Concepto | Palabras gatillo (ES) | (EN) | Emoji |
|---|---|---|---|
| Dinero | euro, euros, dinero, pagar, pago, gratis, precio, caro, barato, cuota, suscripción | money, pay, free, dollar, price | 💸 💰 🤑 |
| Sonido / audio | sonido, audio, voz, escucha, oye, ruido, micrófono, grabar | sound, listen, noise, mic | 🔊 🎙️ 🎧 |
| Vídeo / edición | vídeo, editar, edición, cortar, montaje, clip, cámara | video, edit, cut, clip | 🎬 ✂️ 🎥 |
| Crecimiento / mejora | mejorar, mejor, crecer, subida, aumento, x2, récord, resultado | growth, better, boost, up | 📈 🚀 🔥 |
| Caída / problema | peor, caer, error, fallo, problema, pérdida | down, fail, broken | 📉 💀 ❌ |
| Crear / idea | crear, hacer, construir, idea, inventar | create, build, idea | ✨ 🛠️ 💡 |
| Tiempo | segundo, minuto, hora, día, semana, año, rápido, tarde | time, fast, today | ⏰ ⏳ 📅 |
| Atención / secreto | ojo, mira, escucha esto, secreto, truco, importante | look, secret, trick | 👀 🤫 ⚠️ |
| Personas / audiencia | tú, gente, todos, audiencia, suscriptor | you, people, audience | 🫵 👥 |
| Aprobación / cierre | listo, perfecto, hecho, fin, listo, clavo, exacto | done, perfect, exactly | ✅ 💯 🎯 |
| Estadística / datos | porcentaje, número, dato, estudio, media | percent, data, study | 📊 📉 🧠 |
| Comida | comer, comida, receta, cocinar | food, recipe | 🍔 🥘 |

Cuando el discurso es técnico de un dominio (audio, código, fitness…), los emoji del
dominio ganan sobre los genéricos: para un vídeo de audio, 🎙️/🔊 > 💡 aunque la palabra
sea "idea de sonido".

Anti-patrones:
- Emoji decorativo sin vínculo ("hola" → 👋 en cada saludo).
- Dos stickers en la misma tarjeta de subtítulo (ruido visual).
- Emojis en el texto del ASS: libass no renderiza color emoji (tofu). Siempre PNG vía PIL.
